# Retail Store Sales Analysis

## 📊 Project Overview
An interactive Power BI dashboard designed to analyze retail store sales, customer behavior, product performance, profitability, and business insights.

## 🎯 Objectives
- Analyze overall sales and profit
- Compare store performance
- Identify top-performing products and categories
- Analyze customer segments
- Track payment methods and returns
- Generate actionable business insights

## 🛠️ Tools Used
- Power BI
- Microsoft Excel
- DAX
- Data Visualization

## 📈 Dashboard Pages
1. Overview
2. Store & Product Analysis
3. Customer Analysis

## 💡 Key Insights
The dashboard provides an interactive view of sales, profit, customers, products, stores, and other key business metrics.
